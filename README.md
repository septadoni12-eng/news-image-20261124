# news-image-20261124

One image summing up the world's news of **Tuesday, 24 November 2026**:
36 stories across 7 regions on one front page.

- **Leads:** Asia's Tuesday bounce on Wall Street's historic Monday
  rebound; the Khan Younis airstrike (≥3 killed); the Ulleung Island
  airspace scare (aircraft origin disputed — framed as unconfirmed).
- **Also on the page:** a DATE-CHECK box (6 stories that broke Monday
  23 Nov + 2 not-yet items), per-story CONFIRMED / FORECAST / REPORTED
  tags with a legend, a UTC timeline, a markets strip (Monday closes
  labelled MON, Tuesday opens labelled TUE), region counts, and a small
  numbered-pin world map.
- All spot illustrations are flat programmatic scenes drawn with the
  shared `spot_illustrator` primitives library; no photos, no
  generated images.
- `main.py` copies the committed `entry.png` to `MAKEFUN_OUTPUT_DIR`
  (Python 3.13, standard library only). It runs twice byte-identically.
